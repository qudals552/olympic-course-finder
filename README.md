# 올림픽 강좌 찾기

한국체육산업개발(주)이 공공데이터포털에 개방한 스포츠센터 강좌 데이터로 만든 **강좌 탐색 웹 서비스**입니다.
올림픽수영장·올림픽공원스포츠센터·분당·일산 4개 센터의 강좌를 한 화면에서 찾고 비교합니다.
(2026년도 한국체육산업개발 공공데이터 활용 경진대회 출품작)

- 서버·로그인·광고 없는 정적 웹 서비스입니다. 입력한 검색 문장과 담은 강좌는 이용자 브라우저에만 저장됩니다.
- 신청과 결제는 공식 페이지에서 합니다. 이 서비스는 신청 전 탐색·비교를 돕습니다.

## 사용한 공공데이터

공공데이터포털(data.go.kr)의 한국체육산업개발(주) 파일 데이터입니다. 원본은 `data/raw/`에 있습니다(CP949 인코딩 CSV).

| 데이터 | 번호 |
|---|---|
| 올림픽수영장 강좌정보 | 15101610 |
| 올림픽스포츠센터 강좌정보 | 15110953 |
| 일산스포츠센터 강좌정보 | 15114776 |
| 분당스포츠센터 강좌정보 | 15118652 |
| 스포츠센터 강좌 정보(통합) | 15147992 |

## 구성

```
data/raw/        원본 CSV
src/             데이터 정리 스크립트 (build_courses.py)
data/courses.json  정리 결과 (스크립트가 생성)
site/            웹 화면 (Vite + TypeScript, 프레임워크 없음)
```

## 실행

```bash
cd site
npm install
npm run dev        # 개발 서버
npm test           # 단위 테스트
npm run build      # site/dist 에 배포용 파일 생성
```

## 데이터 갱신

공공데이터포털에서 새 CSV를 받아 `data/raw/`에 덮어쓴 뒤 다음을 실행합니다.

```bash
cd site
npm run data    # 정리 스크립트를 실행해 data/courses.json 과 data/build_report.md 를 만들고, site/public/ 으로 복사
```

원본의 컬럼이 바뀌었거나 수록 강좌 수가 크게 줄면 스크립트가 파일·컬럼을 알려 주고 멈추며, 기존 결과를 덮어쓰지 않습니다.
의도한 변화라면 `--force`를 붙여 다시 실행합니다.

## 배포

`main` 브랜치에 올리면 GitHub Actions(`.github/workflows/pages.yml`)가 테스트와 빌드를 거쳐 GitHub Pages에 배포합니다.

## 알아 둘 점

- 데이터에는 남은 자리(잔여 인원)가 없습니다. 신청 가능 여부는 공식 페이지에서 확인해야 합니다.
- 수준·대상은 별도 컬럼이 없어 강좌명에서 규칙으로 읽어 냅니다.
- 공식 페이지 링크는 강좌별이 아니라 종목별입니다.
